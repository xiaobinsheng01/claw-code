# A股分析

规则与权重以 **Canvas 为唯一正文**；本 skill 只规定何时读什么、允许改什么、产出格式。不要在本文件里改权重或硬约束。

## 分层

自下而上。下层没齐，上层停写。Skill 不重写第 1–3 层的表，只调度。

| 层 | 放什么 | 正文在哪 | 本 skill 做什么 |
| --- | --- | --- | --- |
| 1 资料数据 | 渠道、时点、时间戳、缺口 | 渠道 canvas + 流程里的采集时钟 | 按模式决定扫哪些渠道；过期数整格作废 |
| 2 规则定义 | 权重、标签、W8、H、板块三态、大盘四态 | 流程 canvas + 合订板 canvas | 只引用，不在这里改数字 |
| 3 账户状态 | 股数、成本、可用、最近一稿行为分、修复日计数、板块状态 | **不在 canvas**。上一份结论的第 1–2 行 | 每次产出必须原样带上，供下一轮盘中接着用 |
| 4 判定 | 行为分、板块看涨、大盘四态 | 合订板计算 + 流程第 9–11 步 | 终分/初分全算；盘中只重算 W6 与板块只数 |
| 5 执行 | 9:15 卖出股数；盘中是否现在动 | 流程硬门 | 终分之后才改单；盘中只核对卖出区 |
| 6 产出 | 收盘五行，或盘中六行 | 本文件末段模板 | 按模式选一种，不混写 |

## 三种模式

### A. 次日 9:00 终分（才允许按新分执行 9:15 单）

1. 扫执行流程里「次日 9:00 全扫」+ 官方渠道表（央行、联播、新华社 news.cn、发改委 ndrc.gov.cn、中证网、三报、其余部委、交易所融资、巨潮、美股现金、CME、商品）。新华社、发改委按「取数」节核对时间戳；与已入账事实重复的不另加分。
2. 终分 **替换** 昨晚初分；写明「初分 → 终分」哪些项变了。
3. 完整顺序：资料 → W8/W7 → 行为分 → 板块看涨 → **大盘四态** → 五行结论。
4. 指数硬区间、窄区间、对冲、托住和国家队措辞按「预测」节写。窄区间用上一份收盘对照改过的上下沿，不沿用已经未命中的窄区间。
5. 终分完成后，才确认 9:15 卖出价位与股数。盘中现价用 `close_inputs.py --fast`。

### B. 15:10 起初分 + 19:35 / 17:10 补扫

1. **15:10**：指数、成交、涨跌家数、涨停池、持仓现价；上证 50、沪深 300、中证 1000（缺任一条则指数句停机）。对冲、托住和底仓股价还要中证银行、CSSW 电子；电子缺失时只把对冲写成未核。
2. **16:30**：龙虎榜原文（持仓是否上榜）。
3. **17:10**：央行官网公开市场（打不开标未复核，转载不算已核对）。
4. **19:35**：联播文字目录、新华社 news.cn 当日带时间戳的通稿和受权播发、发改委 ndrc.gov.cn 新闻发布会与通知、央视财经、中证网头版。15:00 后挂出的稿进当晚初分，次日 9:00 再打开官网确认后进终分，不改已收盘的买卖。
5. **19:40**：上期所日盘结算、巨潮。
6. 先跑 `python3 .cursor/skills/a-share-analysis/scripts/close_inputs.py`。指数、家数、涨停行业、修复三项、`structure` 里的对冲、托住、`book_price`、卖出区以脚本输出为准。脚本把 5 日成交额标成缺口时，W6 量能不打分。股数锚不由这支脚本更新。
7. 产出初分行为分 + 板块状态 + 大盘四态，并按「预测」节写早盘对照。**不**因初分改次日 9:15 已锁定的终分单（若尚未终分，卖出仍按 H 规则预告）。

### C. 盘中实时（用户随时问，或 9:45 / 11:30 / 13:05）

**允许改的只有四项**（与执行流程一致）：

- W6 原料（家数、涨停/跌停/炸板、溢价、高度、成交）
- 持仓现价与是否进入卖出区
- 30 分钟笔 / 买卖点（未完成则仍 W7=0）
- 板块涨停 **只数**（重算板块状态：未核 / 不成立 / 候选）

**禁止：**

- 因盘中板块候选、普涨、或银行下跌，把行为分标签从震荡改成可开仓。
- 因实时分析取消金螳螂只卖、中信 9.55 减 1000、或万向/机器人开仓（除非用户明确改 H，且仍要行为分 ≥ 0.4、金螳螂 ≤6000、板块候选）。
- 用界面新闻上午北向快照充收盘净买入；北向无净买入字段则写缺口。
- 在盘中重算 W1–W5、W8 报告期、跨资产（除非用户说 **突发硬新闻** 且给出央行、新华社、发改委或联播出处；此时只更新受影响权重并标明「盘中例外」，仍不写开仓）。

**盘中优先数据源（快）：**

- 现价：`qt.gtimg.cn`
- 情绪/涨停：选股宝收盘前用 flash/API；东财 push2 502 时换腾讯 + 选股宝
- 不为此模式全扫巨潮、联播、新华社、发改委（留到 19:35 或次日 9:00）

**盘中产出（短，六行以内）：**

1. 时点 + 上证/创业板/科创 50 现价与日内高低。
2. W6 相对上一盘是否变（变则写方向，不变写「W6 锁」）。
3. 大盘四态 **仅写当日**：修复日计数（0/1/2/3）、流出端（银行/煤炭/有色/…）、是否满足三项修复条件；不写月末托底/抽血，也不改国家队股数锚。
4. 板块一行：状态是否因只数变化而升级（默认仍不进权重）。
5. 每只持仓：现价 vs 卖出区/9.55，是否 **现在** 该动（仍服从 H）。
6. 一句：行为分仍用 **最近终分/初分** 分数，除非硬新闻例外。

## 大盘四态（不进 W1–W8）

收盘或用户问大盘时，按流程 canvas 写指数句。对冲、托住和国家队底仓的核对句在「预测」节：

1. **托底**（月末）：上证 50 月跌幅比创业板少 10pp+ 且银行月线收涨 → 只解释少跌。
2. **抽血**（月末）：银行月涨 + 电子/通信月跌 15%+ + 行业下跌过半 → 银行新高不写成转强。
3. **修复日**（每日）：银行或煤炭收跌 + 沪深 300 涨幅 < 中证 1000 + 茅台/宁德行业收涨 → 三项齐记 1 日；连续 3 日齐才「修复成立」。
4. **分流**：流出端 = 当日收跌的高权重行业；石油、移动、白酒与银行分开。
5. **不进分**：以上各条和国家队底仓不进 W1–W8。修复成立也不新开仓（行为分 < 0.4 仍只执行减仓）。
6. **对冲**（每日）：中证银行 `399986` 与 CSSW 电子 `399811` 收盘一涨一跌 → `structure.hedge = opposite`，并写跌的一侧。一方平盘或两边同向 → `same_or_flat`，写未对冲。月线两边同号不取消当日对冲。成长一侧用科创芯片 `000685`、国证通信 `399389`、创业板 `399006`、科创 50 `000688` 看是不是成组下跌。新能源 `000941` 与银行反向也不算对侧。
7. **托住**（上证收跌才核）：排序只用 2026-07-01 至 2026-11-03 这 84 个交易日里的 39 个上证下跌日，看中位数和收涨天数。主托是中证银行：中位数 +0.53%，25/39 收涨。银行当日收涨 → `bank_held`；否则 → `bank_did_not_hold`。第二托是食品饮料 `000807`：中位数 +0.09%，22/39 收涨。食品饮料当日收涨 → `food_held`，否则 → `food_did_not_hold`。第二托不替代主托。中证白酒下跌日中位数 -0.28%，只 16/39 收涨，平均 +0.18% 也不升主托、不进第二托。创业板跌幅达到或超过 1% 的 36 天里，再登记食品饮料、中证白酒、红利谁收涨，记在 `secondary_cushion`（这 36 天白酒平均 +0.46%、18/36，红利平均 +0.22%、20/36）。上证 50 涨跌幅高于创业板 → `weights_fell_less`。煤炭、能源、油气、证券、有色、红利的区间上涨只说明这四个月的路径，下跌日不写进托住。月初未走完时，不因几天银行收跌把主托改成白酒或食品饮料。
8. **国家队底仓**（不改主托）：主体只写中央汇金投资、中央汇金资产管理、证金。国金基金留在公募，不进这句。股数锚是 2026-09-30 汇金投资 8 只十大流通股东「不变」，脚本字段 `national_team_share_anchor`。下一份季报或持有人名单打开前，不把银行收涨写成汇金当日买入。日频与银行托住同一条件：上证收跌且中证银行收涨 → `book_price_held`（底仓股价托住）；上证收跌且银行未涨 → `book_price_did_not_hold`；上证未收跌 → `not_applicable`。样本只用 2026-07-31 收盘到 2026-11-03：这 8 只未复权市值 4.87 万亿 → 5.30 万亿，其中四大行 +4639 亿，申万、中信建投、中金、新华合计 −341 亿。这四只不进托住。宽基 ETF 净申购写「宽基申赎」；2026-05-01 起没有持有人名单，不写成汇金买入。国新、诚通的股数变化单独记。下一份报告里四大行股数下降，停用「底仓未减」，改写汇金减了银行股；股数增加则另写汇金加了银行股，与当日 `book_price` 分成两句。

## 预测

目标是下一次收盘能逐条核对。写不出核对条件的句子不算预测。权重和硬门不因对错而改。

### 指数区间

- 先写硬区间，再写「更可能收在」的窄区间。窄区间落在硬区间里面。
- 窄区间上沿不高于上一交易日高点。站上昨日高点才看更高，这一条单独写，不写进窄区间。
- W3 为负、并且写了开盘受压时，窄区间上沿用上一交易日收盘，下沿用硬区间下沿和上一交易日低点里较高的那个。窄区间不放在硬区间上半段。
- 收盘靠近当日最低、且高点等于开盘时，下一交易日上沿改为这一日高点，下沿改为这一日低点。收盘守住的整数位单独写。
- 昨日上涨家数不外推成今日上沿。盘前 W6 只表示昨日事实。

11 月 3 日的核对：硬区间 3600–3660，收盘 3608，落在里面。窄区间写成 3620–3650，未落在。当天 W3 为负，按本规则窄区间应是 3600–3638。下一日上沿用 3624.58，下沿用 3580.38。

### 修复日

预测下一天是否记入修复时，把三项各写会或不会：银行或煤炭收跌；沪深 300 涨幅低于中证 1000；中证白酒收涨（茅台所在行业）。不用「银行翻红」代替第二项。收盘用脚本里的 `repair.all_three`。缺一项，计数不加。宁德时代个股上涨不代替电力设备行业。

### 对冲与托住

早盘在修复三项之外再写两句。收盘用 `structure` 打勾。这两句不进权重，不改 9.55，也不改金螳螂只卖。

样本是 2026-06-30 收盘到 2026-11-03，84 个交易日。7 月上证 50 少跌 20.8 个百分点且银行月线收涨，10 月少跌 20.1 个百分点且银行月线收涨，这两月记托底。9 月只少 5 个百分点，不记。8 月上证 +4.0%、电子 +10.1%，21 天里银行与电子方向相反 15 天，当天仍写对冲。

- 对冲写「相反」或「同向」。写相反时，跌的一侧只写「成长」或「银行」。成长指电子、科创芯片、通信、创业板、科创 50。整月两边同号时，仍按当天方向写。
- 上证若收跌，银行写「托住」或「未托」，食品饮料另写「第二托」或「未托」。白酒不写进这两句。同时预判创业板跌幅达到或超过 1% 时，次托只点名食品饮料、白酒、红利里预期收涨的；不点名则收盘只登记事实，不记早盘对错。
- 煤炭、能源、油气、红利、白酒这四个月的区间涨幅不写进托住。
- 对冲且跌的一侧是成长：窄区间放在硬区间下半段。上沿仍服从上一节。
- 预判创业板跌幅达到或超过 1%：上证下沿按上证自己的硬区间写，不把创业板跌幅换算成上证点位。
- 预判成长为跌的一侧、并且银行或白酒收红：修复第二项写不会，修复计数不加。同一天可以是银行未托，同时修复三项不齐。

11 月 3 日核对：银行 -0.39%，电子 -5.83%，同向，未对冲。上证 -0.82%，银行未托。食品饮料 +1.93%，记第二托。创业板 -2.73%，次托为食品饮料和白酒 +1.54%，红利 -0.16% 不登记。白酒这天收涨，不升成主托。上证 50 +0.21%、创业板 -2.73%，权重少跌。沪深 300 -0.20% 高于中证 1000 -1.71%，修复不加。新能源 +1.68% 与银行反向，不记成对冲。

### 国家队底仓

早盘在托住那句后面加半句，不另做一条区间预测。收盘用 `structure.book_price` 和 `national_team_share_anchor`。

- 股数锚写「2026-09-30 不变，直到下一份季报」。不预测汇金当日买卖。
- 上证若收跌且银行预判收涨，措辞写「底仓股价托住」。银行预判收跌，写「底仓股价未托」。
- 国金基金、汇金名下的申万宏源、中信建投、中金公司、新华保险，以及没有持有人名单的宽基 ETF 申购，都不写进这半句。
- 这半句不进权重，不改 9.55，不改金螳螂只卖。

11 月 3 日：上证收跌、银行 -0.39%，`book_price_did_not_hold`。7 月 31 日到 11 月 3 日市值上升，不把这一天改成托住。

### 收盘对照

15:10 初分在五行后面加表，每行只写落在或不落在：

| 早盘写的 | 收盘 | 差 |
| --- | --- | --- |
| 硬区间 | 上证收盘 | 点位 |
| 窄区间 | 上证收盘 | 点位 |
| 修复日计数 | `repair.all_three` | 哪一项没齐 |
| 对冲 | `structure.hedge`、`down_side` | 相反或同向；跌的一侧 |
| 银行托住 | `structure.bank_cushion` | 上证未收跌则写不适用 |
| 国家队措辞 | `structure.book_price`、`national_team_share_anchor` | 与银行托住同向。只写底仓股价。股数锚仍是 2026-09-30 不变时，不写汇金当日加仓 |
| 食品饮料第二托 | `structure.food_cushion` | 上证未收跌则写不适用。不替代银行 |
| 次托 | `chinext_down_at_least_1pct`、`secondary_cushion` | 创业板跌幅未到 1% 则写不适用 |
| 窄区间位置 | 收盘在硬区间上半或下半 | 早盘写了下半段才核 |
| W6 | 今日家数、涨停、炸板率、溢价 | 相对昨日锁住的那一格 |
| 金螳螂 3.88 | 开盘、最高、最低 | 卖出条件是否成立 |
| 中信 9.55 | 最高、收盘 | 是否仍低于 9.55 |

下一交易日的窄区间按上一节从这张表改。

### 个股标记

用户问非持仓时，在不开仓之外可以标一条，不进 W1–W8：涨停次日高开、尾盘 14:55–14:57 才封板、价格离开卖出区。标记不打开新仓。

低价尾盘扫描覆盖收盘价 10 元及以下、当日有成交的全部 A 股，不按成交额页截断。14:55–14:57 与 14:57–15:00 分开记。

### 取数

- 现价和当日成交额：`qt.gtimg.cn`。两市成交额是上证加深证，单位是亿元。
- 家数、涨停、炸板、昨涨停溢价：选股宝 `market_indicator/latest`，时间戳要对到 15:00。
- 涨停行业和高度：东财涨停池。与选股宝只数不一致时，家数用选股宝，行业用东财，并写出两只数。
- 美股只用现金收盘。期货涨跌幅基期对不上现金收盘时整格不用。
- 5 日成交额取不到就空着，不估一个数来把 W6 打到 +2 或 -1。
- 新华社：打开 news.cn 带发布时间的通稿和受权播发。15:00 后的稿进当晚 19:35 初分，次日 9:00 再确认后进终分，不改当天已经收盘的买卖。

- 同一事实只记一次。和 2026-03-13《纲要》或 2026-03-06 郑栅洁答问重复的「2025 年近 6 万亿、2030 年超过 10 万亿」不另加 W1、W2。新的产量数字记入 W2 原料，不因此把 W2 从 -1 改掉。2026-11-03 集成电路产量 4428 亿块、同比 +23.3% 按这条记，W2 维持 -1，收盘初分仍是 -0.02，本轮不重算。

## 硬门（任何模式）

- 行为分 < 0.4：板块候选也不买；盘中普涨不算例外。
- 金螳螂：只卖；机构正分也不买。
- 中信：现价 < 9.55 → 减 1000；板块/银行/修复不能取消。
- 指数句不得松于行为标签（震荡不说成偏进攻）。

## 状态块（每次结论都带）

账户状态不进 canvas。收盘五行和盘中六行的前面，先写这一块，下一轮盘中只读它，不重算 W1–W5：

- 稿：初分或终分，北京时间
- 行为分、标签
- 修复日计数（0–3），流出端
- 板块状态
- 持仓：代码、股数、可用、成本、现价、卖出动作

用户没给新的成交截图时，股数沿用上一块，并写「股数未更新」。
