# A股分析

规则与权重以 **Canvas 为唯一正文**；本 skill 只规定何时读什么、允许改什么、产出格式。不要在本文件里改权重或硬约束。

## 分层

自下而上。下层没齐，上层停写。Skill 不重写第 1–3 层的表，只调度。

| 层 | 放什么 | 正文在哪 | 本 skill 做什么 |
| --- | --- | --- | --- |
| 1 资料数据 | 渠道、时点、时间戳、缺口 | 渠道 canvas + 流程里的采集时钟 | 按模式决定扫哪些渠道；过期数整格作废 |
| 2 规则定义 | 权重、标签、W8、H、板块三态、大盘四态 | 流程 canvas + 合订板 canvas | 只引用，不在这里改数字 |
| 3 账户状态 | 最近一稿行为分、修复日计数、板块状态。股数、可用、成本、上一笔是否成交 | **不在 canvas**。分数和板块沿用上一份结论。持仓在初分向用户要，终分用这份 | 初分没提供就写「待提供」。终分不另要一次 |
| 4 判定 | 行为分、板块看涨、大盘四态 | 合订板计算 + 流程第 9–11 步 | 终分/初分全算；盘中只重算 W6 与板块只数 |

## 三种模式

### A. 次日 9:00 终分（才允许按新分执行 9:15 单）

1. 扫执行流程里「次日 9:00 全扫」+ 官方渠道表（央行、联播、新华社 news.cn、发改委 ndrc.gov.cn、央视财经频道 tv.cctv.com、中国财富网 cfbond.com、中证网、三报、其余部委、交易所融资、巨潮、美股现金、CME、商品、富时中国 A50 夜盘）。新华社、发改委、央视财经频道、中国财富网按「取数」节核对时间戳；与已入账事实重复的不另加分。A50 按「外围」节写高开、平开或低开。
2. 终分 **替换** 昨晚初分；写明「初分 → 终分」哪些项变了。
3. 完整顺序：资料 → W8/W7 → 行为分 → 板块看涨 → **大盘四态** → 五行结论。上证日线四格没齐，W7 不打分，也不记 0。卖出股数仍按硬门。
4. 指数硬区间、窄区间、A50 方向、对冲、托住和国家队措辞按「预测」节写。窄区间用上一份收盘对照改过的上下沿，不沿用已经未命中的窄区间。
5. 终分完成后，才确认 9:15 卖出价位和股数。股数用当晚初分里用户已提供的持仓。初分仍是「待提供」时，终分只写价位，不编股数。盘中现价用 `close_inputs.py --fast`。

### B. 15:10 起初分 + 19:35 / 17:10 补扫

1. **15:10**：指数、成交、涨跌家数、涨停池、持仓现价；上证 50、沪深 300、中证 1000（缺任一条则指数句停机）。对冲、托住和底仓股价还要中证银行、CSSW 电子；电子缺失时只把对冲写成未核。
2. **16:30**：龙虎榜原文（持仓是否上榜）。
3. **17:10**：央行官网公开市场（打不开标未复核，转载不算已核对）。
4. **19:35**：联播文字目录、新华社 news.cn 当日带时间戳的通稿和受权播发、发改委 ndrc.gov.cn 新闻发布会与通知、央视财经频道当日已挂出的第一时间、正点财经、交易时间、天下财经、中国财富网要闻列表里来源写成中国财富网的当日稿、中证网头版。**21:20**：经济信息联播和 15:00 后才挂出的正点财经，19:35 还没有的补进初分附录。中国财富网 19:35 之后才挂出的，留到次日 9:00，不单开附录。15:00 后挂出的稿进当晚初分，次日 9:00 再打开栏目页确认后进终分，不改已收盘的买卖。
5. **19:40**：上期所日盘结算、巨潮。
6. 先跑 `python3 .cursor/skills/a-share-analysis/scripts/close_inputs.py`。指数、家数、涨停行业、修复三项、`structure` 里的对冲、托住、`book_price`、卖出区以脚本输出为准。脚本把 5 日成交额标成缺口时，W6 量能不打分。股数锚不由这支脚本更新。
7. 产出初分行为分 + 板块状态 + 大盘四态，并按「预测」节写早盘对照。上证和每只持仓按「缠论」节写日线四格。**不**因初分改次日 9:15 已锁定的终分单。初分向用户要股数、可用、成本、上一笔是否成交。还没提供时，价位条件照写，持仓写「待提供」。

### C. 盘中实时（用户随时问，或 9:45 / 11:30 / 13:05）

**允许改的只有四项**（与执行流程一致）：

- W6 原料（家数、涨停/跌停/炸板、溢价、高度、成交）
- 持仓现价与是否进入卖出区
- 30 分钟买卖点。只改卖出节奏，不改日线笔的方向。日线四格没齐，W7 保持缺口，不记 0
- 板块涨停 **只数**（重算板块状态：未核 / 不成立 / 候选）

**禁止：**

- 因盘中板块候选、普涨、银行下跌、托住、修复或 30 分钟买点，把行为分标签从震荡改成可开仓。
- 把日线向下笔改成向上，或把 W7 缺口记成 0。
- 因实时分析取消金螳螂只卖、中信 9.55 减 1000、或万向/机器人开仓（除非用户明确改 H，且仍要行为分 ≥ 0.4、金螳螂 ≤6000、板块候选）。
- 用界面新闻上午北向快照充收盘净买入；北向无净买入字段则写缺口。
- 在盘中重算 W1–W5、W8 报告期、跨资产（除非用户说 **突发硬新闻** 且给出央行、新华社、发改委、央视财经频道、中国财富网或联播出处；此时只更新受影响权重并标明「盘中例外」，仍不写开仓）。中国财富网的转载不构成突发硬新闻。

**盘中优先数据源（快）：**

- 现价：`qt.gtimg.cn`
- 情绪/涨停：选股宝收盘前用 flash/API；东财 push2 502 时换腾讯 + 选股宝
- 不为此模式全扫巨潮、联播、新华社、发改委、央视财经频道、中国财富网（留到 19:35、21:20 或次日 9:00）

**盘中产出（短，六行以内）：**

1. 时点 + 上证/创业板/科创 50 现价与日内高低。
2. W6 相对上一盘是否变（变则写方向，不变写「W6 锁」）。
3. 大盘四态 **仅写当日**：修复日计数（0/1/2/3）、流出端（银行/煤炭/有色/…）、是否满足三项修复条件；不写月末托底/抽血，也不改国家队股数锚。
4. 板块一行：状态是否因只数变化而升级（默认仍不进权重）。
5. 持仓用最近一份终分里的数字。终分仍是「待提供」时，这一行写「待提供」，不新写股数。已提供时，每只写现价 vs 卖出区/9.55，是否现在该动（仍服从 H）。30 分钟卖点可以提前减，股数仍按硬门。30 分钟买点不写进动作。
6. 一句：行为分仍用 **最近终分/初分** 分数，除非硬新闻例外。

## 大盘四态（不进 W1–W8）

收盘或用户问大盘时，按流程 canvas 写指数句。对冲、托住和国家队底仓的核对句在「预测」节：

1. **托底**（月末）：上证 50 月跌幅比创业板少 10pp+ 且银行月线收涨 → 只解释少跌。
2. **抽血**（月末）：银行月涨 + 电子/通信月跌 15%+ + 行业下跌过半 → 银行新高不写成转强。
3. **修复日**（每日）：银行或煤炭收跌 + 沪深 300 涨幅 < 中证 1000 + 茅台/宁德行业收涨 → 三项齐记 1 日；连续 3 日齐才「修复成立」。
4. **分流**：流出端 = 当日收跌的高权重行业；石油、移动、白酒与银行分开。
5. **不进分**：以上各条和国家队底仓不进 W1–W8。修复成立也不新开仓（行为分 < 0.4 仍只执行减仓）。
6. **对冲**（每日）：中证银行 `399986` 与 CSSW 电子 `399811` 收盘一涨一跌 → `structure.hedge = opposite`，并写跌的一侧。一方平盘或两边同向 → `same_or_flat`，写未对冲。月线两边同号不取消当日对冲。成长一侧用科创芯片 `000685`、国证通信 `399389`、创业板 `399006`、科创 50 `000688` 看是不是成组下跌。新能源 `000941` 与银行反向也不算对侧。
7. **托住**（上证收跌才核）：排序只用 2026-07-01 至 2026-11-03 这 84 个交易日里的 39 个上证下跌日，看中位数和收涨天数。主托是中证银行：中位数 +0.53%，25/39 收涨。银行当日收涨 → `bank_held`；否则 → `bank_did_not_hold`。第二托是食品饮料 `000807`：中位数 +0.09%，22/39 收涨。食品饮料当日收涨 → `food_held`，否则 → `food_did_not_hold`。第二托不替代主托。中证白酒下跌日中位数 -0.28%，只 16/39 收涨，平均 +0.18% 也不升主托、不进第二托。创业板跌幅达到或超过 1% 的 36 天里，再登记食品饮料、中证白酒、红利、保险主题谁收涨，记在 `secondary_cushion`（这 36 天白酒平均 +0.46%、18/36，红利平均 +0.22%、20/36）。上证 50 涨跌幅高于创业板 → `weights_fell_less`。煤炭、能源、油气、证券、有色、红利的区间上涨只说明这四个月的路径，下跌日不写进托住。月初未走完时，不因几天银行收跌把主托改成白酒或食品饮料。同一窗口再核过、下跌日中位数仍为负、不升主托也不进第二托：保险主题 `399809` 中位数 −0.18%，19/39；中证煤炭 `399998` −0.16%，14/39；中证能源 `000928` −0.48%，15/39；国证油气 `399439` −0.93%，10/39；全指医药 `000991` −0.57%，12/39；绿色电力 `399438` −0.09%，17/39；国证交运 `399433` −0.09%，19/39；800非银 `399966` −0.76%，12/39。中证传媒 `399971` −1.16%，14/39，全指信息 `000993` −2.80%，2/39，这两条跟成长一侧，不进老登托住。创业板跌幅达到或超过 1% 的 36 天里，保险主题中位数 +0.25%、平均 +0.40%、20/36 收涨，与红利一起只登记进 `secondary_cushion`，不升第二托。个股五日涨跌不改指数托住。古井贡酒、泸州老窖、海尔智家、中国太保、片仔癀、上海银行只记标记。上海银行 2026-11-02 单日 −8.81% 不改当日中证银行的托住判定。家电指数当前从 `qt.gtimg.cn` 取不到。美的、格力、海尔三只等权在这 39 个下跌日中位数 +0.20%、24/39，先放在样本外，不新开托；指数能取到后再用同一窗口重核。
8. **国家队底仓**（不改主托）：主体只写中央汇金投资、中央汇金资产管理、证金。国金基金留在公募，不进这句。股数锚是 2026-09-30 汇金投资 8 只十大流通股东「不变」，脚本字段 `national_team_share_anchor`。下一份季报或持有人名单打开前，不把银行收涨写成汇金当日买入。日频与银行托住同一条件：上证收跌且中证银行收涨 → `book_price_held`（底仓股价托住）；上证收跌且银行未涨 → `book_price_did_not_hold`；上证未收跌 → `not_applicable`。样本只用 2026-07-31 收盘到 2026-11-03：这 8 只未复权市值 4.87 万亿 → 5.30 万亿，其中四大行 +4639 亿，申万、中信建投、中金、新华合计 −341 亿。这四只不进托住。宽基 ETF 净申购写「宽基申赎」；2026-05-01 起没有持有人名单，不写成汇金买入。国新、诚通的股数变化单独记。下一份报告里四大行股数下降，停用「底仓未减」，改写汇金减了银行股；股数增加则另写汇金加了银行股，与当日 `book_price` 分成两句。

## 预测

目标是下一次收盘能逐条核对。写不出核对条件的句子不算预测。权重和硬门不因对错而改。

### 指数区间

- 先写硬区间，再写「更可能收在」的窄区间。窄区间落在硬区间里面。
- 窄区间上沿不高于上一交易日高点。站上昨日高点才看更高，这一条单独写，不写进窄区间。
- W3 为负时，窄区间放在硬区间下半段。富时中国 A50 夜盘低开时，上沿再用上一交易日收盘，下沿用硬区间下沿和上一交易日低点里较高的那个。
- 收盘靠近当日最低、且高点等于开盘时，下一交易日上沿改为这一日高点，下沿改为这一日低点。收盘守住的整数位单独写。
- 昨日上涨家数不外推成今日上沿。盘前 W6 只表示昨日事实。

11 月 3 日的核对：硬区间 3600–3660，收盘 3608，落在里面。窄区间写成 3620–3650，未落在。当天 W3 为负，窄区间应落在 3600–3660 的下半段。下一日上沿用 3624.58，下沿用 3580.38。

### 外围

只在 9:00 终分写一句，不进 W1–W8，不改 W7，不改 9.55，不改金螳螂只卖。初分不写。

富时中国 A50 夜盘：最新价相对前结。绝对值小于 0.20% 写平开，达到或超过 0.20% 写高开或低开，并写涨跌幅和报价的北京时间。没有最新价和前结，整句写缺口。

美股现金、美债、原油、沪铜、美元仍按原清单进入 W3 和跨资产。恒生科技、日经、欧洲不单列。

A50 低开时，窄区间上沿用上一交易日收盘。A50 高开或平开时，上沿仍不高于上一交易日高点。A50 为缺口且 W3 为负时，窄区间仍放在硬区间下半段。

### 修复日

预测下一天是否记入修复时，把三项各写会或不会：银行或煤炭收跌；沪深 300 涨幅低于中证 1000；中证白酒收涨（茅台所在行业）。不用「银行翻红」代替第二项。收盘用脚本里的 `repair.all_three`。缺一项，计数不加。宁德时代个股上涨不代替电力设备行业。

### 对冲与托住

早盘在修复三项之外再写两句。收盘用 `structure` 打勾。这两句不进权重，不改 9.55，也不改金螳螂只卖。

样本是 2026-06-30 收盘到 2026-11-03，84 个交易日。7 月上证 50 少跌 20.8 个百分点且银行月线收涨，10 月少跌 20.1 个百分点且银行月线收涨，这两月记托底。9 月只少 5 个百分点，不记。8 月上证 +4.0%、电子 +10.1%，21 天里银行与电子方向相反 15 天，当天仍写对冲。

- 对冲写「相反」或「同向」。写相反时，跌的一侧只写「成长」或「银行」。成长指电子、科创芯片、通信、创业板、科创 50。整月两边同号时，仍按当天方向写。
- 上证若收跌，银行写「托住」或「未托」，食品饮料另写「第二托」或「未托」。白酒、保险不写进这两句。同时预判创业板跌幅达到或超过 1% 时，次托只点名食品饮料、白酒、红利、保险主题里预期收涨的；不点名则收盘只登记事实，不记早盘对错。

## 缠论（W7）

日线做判断，30 分钟做操作。分数只取上证日线。每只持仓另写四格，不进分数。笔和中枢不由 `close_inputs.py` 生成。托住、修复、对冲、国家队底仓不改 W7。3.88–4.00 和 9.55 仍是风控价，不写成一类、二类、三类买卖点。

四格缺一格就是缺口：

1. 笔方向，以及起点价、终点价。
2. 中枢上沿、下沿，或「中枢未形成」。
3. 背驰有，或无。
4. 比较的两段：前一段的起止价，这一段的起止价。

缺口不打分，不记 0。行为分注明「W7 未计入」。其余项即使达到 0.4，标签仍按震荡，只减不加。

四格齐了才打分：

| 上证日线 | 分数 |
| --- | --- |
| 中枢已形成，买卖点写无 | 0，并写明中枢震荡 |
| 笔向下，离开段无背驰 | −1 |
| 日线卖点 | −2 |
| 笔向上，离开段无背驰 | +1 |
| 日线买点 | +2 |

日线卖点只认两种：向下笔背驰之后的卖；跌破中枢下沿之后的三卖。日线买点只认两种：向上笔背驰之后的买；离开中枢之后，回抽不进中枢的三买。30 分钟买卖点不进这张表。30 分钟卖点只改卖出节奏，减仓股数仍按硬门。30 分钟买点不改日线笔的方向，也不把震荡改成开仓。

正 T 要另写三句：级别、不破的价、失效价。二买不破一买的低点。三买的回抽不进中枢，失效价是中枢上沿。缺一句，正 T 不成立。

账户里的每一只都写四格。持仓上出现日线买点，也不把 W7 打成正分，不取消金螳螂只卖，不取消 9.55。

## 状态块（每次结论都带）

账户状态不进 canvas。收盘五行和盘中六行的前面，先写这一块，下一轮盘中只读它，不重算 W1–W5：

- 稿：初分或终分，北京时间
- 行为分、标签。W7 没计入时，标签写震荡
- W7：缺口或分数。缺口写「未计入」，不写 0
- 修复日计数（0–3），流出端
- 板块状态
- 持仓：代码、股数、可用、成本、现价、卖出动作。每只另写日线四格。初分未提供则写「待提供」

## 持仓

收盘之后账户不再变动，所以持仓只在初分要一次。终分直接用这份，不再要一次。合订板里的旧持仓表不能当账户。

初分向用户要：每只的股数、可用、成本，以及上一笔卖出是否成交。用户提供之后，写上提供的北京时间。还没提供时，指数、行为分、板块、大盘四态照常写，价位条件保留，持仓写「待提供」。

终分抄当晚初分里已经提供的股数、可用、成本和成交结果，用来写 9:15 的卖出股数。初分仍是「待提供」时，终分只确认价位，不编股数。金螳螂只卖，中信现价低于 9.55 才减仓。

盘中沿用最近一份终分里的持仓。用户说明成交有变时，才改股数。

不对接东方财富软件，也不登录证券账户。公开行情接口没有个人持仓。Choice 量化接口里的组合持仓是终端里自建的组合，不是证券账户。EMT、掘金一类官方交易接口能查持仓，同一套登录也能下单，不接到本技能。不接收资金账号、登录密码、交易密码、Cookie、令牌，也不从软件里抓取登录态。初分只收用户手写的代码、股数、可用、成本、上一笔是否成交。

## 定时唤醒

用户要求后，用 `cursor-subscriptions` 的定时器唤醒本对话。Cron 按 UTC 写。定时只负责到点打开这一轮，醒来后仍按对应模式拉数、算分。非交易日只写「非交易日」，然后仍要续订。定时不在券商挂 9:15 的单。初分向用户要持仓。终分用当晚初分里已提供的数字；初分仍是「待提供」时不编股数。

这组定时暂定到 **2027-02-28（北京时间）** 停止。**2027-02-21** 由周日续期定时写提醒：初分与终分将于 2027-02-28 到期，到期后不再自动跑。2027-02-21 至 2027-02-28 的初分和终分，结论第一行再写一句「定时将于 2027-02-28 到期」。

平台上单次订阅大约 7 天就会到期，到不了 2027 年 2 月。所以每次醒来，只要北京时间早于 2027-02-28，就把下表三个定时退订后按原 cron、原 prompt 重订。已到或超过 2027-02-28，退订这三个，写明已到期，不再重订。重订时 prompt 与当前订阅里的原文一致，不另改口径。

| 稿 | 北京时间 | UTC cron | 名称 |
| --- | --- | --- | --- |
| 终分 | 每个交易日 9:00 | `0 1 * * 1-5` | `a-share-final-0900` |
| 初分 | 每个交易日 21:25 | `25 13 * * 1-5` | `a-share-prelim-2125` |
| 续期 | 每周日 10:00 | `0 2 * * 0` | `a-share-schedule-keeper` |

21:25 这一稿把 15:10 到 21:20 的原料一次收齐。周日续期不写交易稿，只续订；2027-02-21 那天同时写到期提醒。盘中 9:45 / 11:30 / 13:05 的快评另设，用户没有要求就不设。
